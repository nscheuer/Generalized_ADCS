Magnetic Dipole Disturbance Model

Models the disturbance torque generated by a residual (parasitic) magnetic dipole interacting with Earth’s geomagnetic field. This is a passive, non-actuated torque acting on the spacecraft body.

Physical Model

The body-frame torque is

\[\mathbf{T}_d \;=\; \mathbf{m}_d \times \mathbf{B}_b,\]

where

  • \(\mathbf{m}_d\) is the residual dipole vector [A·m²],

  • \(\mathbf{B}_b\) is the geomagnetic field in the body frame [T].

Optionally, stochastic noise is added to \(\mathbf{m}_d\) each step to represent modeling uncertainty or time variability.

Parameters:

  • dipole_torque (numpy.ndarray) – Nominal magnetic dipole vector in body coordinates [A·m²], shape (3,).

  • noise (Noise) – Noise model instance used to perturb the nominal dipole vector.

  • estimate_dist (bool)

class ADCS.satellite_hardware.disturbances.Drag_Disturbance(config)[source]¶

Bases: Disturbance

Aerodynamic Drag Disturbance Model

This class models the aerodynamic drag torque acting on a satellite in low Earth orbit (LEO). The drag force on each exposed surface is computed from the relative atmospheric flow in the body frame, and the net disturbance torque is obtained as the cross product of surface forces with their lever arms from the satellite’s center of mass.

Physical Model

The drag force acting on a satellite surface is modeled as:

\[\mathbf{F}_i = -\tfrac{1}{2} \rho \, C_{D,i} \, A_i \, \max(0, \mathbf{n}_i \cdot \mathbf{V}_b) \, \frac{\mathbf{V}_b}{\|\mathbf{V}_b\|}\]

where:

  • \(\rho\) — Atmospheric density [kg/m³]

  • \(C_{D,i}\) — Drag coefficient of the i-th surface

  • \(A_i\) — Area of the i-th surface [m²]

  • \(\mathbf{n}_i\) — Surface normal (unit vector) in the body frame

  • \(\mathbf{V}_b\) — Relative velocity vector in the body frame [m/s]

The total drag torque acting on the spacecraft is:

\[\mathbf{T}_{\mathrm{drag}} = \sum_i (\mathbf{r}_i - \mathbf{r}_{\mathrm{COM}}) \times \mathbf{F}_i\]

where \(\mathbf{r}_i\) is the centroid of the i-th surface and \(\mathbf{r}_{\mathrm{COM}}\) is the satellite center of mass.

Parameters:

config (GeometryConfig) – Configuration object containing face areas, centroids, normals, and drag coefficients for each surface element.

numfaces¶

Number of discrete surface faces modeled.

Type:

int

areas¶

Surface areas of each face [m²], shape (N,).

Type:

numpy.ndarray

centroids¶

Centroid positions of each face in body coordinates [m], shape (N, 3).

Type:

numpy.ndarray

normals¶

Unit normal vectors of each face in the body frame, shape (N, 3).

Type:

numpy.ndarray

torque_qjac(sat, x, os)[source]¶

Compute the Jacobian of drag torque with respect to the attitude quaternion.

Let \(\mathbf{q}\) be the attitude quaternion inside \(x\). The torque depends on \(\mathbf{q}\) via \(\mathbf{V}_b(\mathbf{q})\) and via the term \(\max(0,\,\mathbf{n}_i^\top\mathbf{V}_b)\). Using \(H(\cdot)\) for the Heaviside function,

\[\frac{\partial}{\partial \mathbf{q}} \max\!\big(0,\ \mathbf{n}_i^\top\mathbf{V}_b\big) = H\!\big(\mathbf{n}_i^\top\mathbf{V}_b\big)\, \mathbf{n}_i^\top\frac{\partial \mathbf{V}_b}{\partial \mathbf{q}}.\]

The resulting Jacobian is consistent with the implemented expression

\[\frac{\partial \mathbf{T}_{\mathrm{drag}}}{\partial \mathbf{q}} = -\tfrac{1}{2}\rho\Big[ \big(\tfrac{\partial F}{\partial \mathbf{q}}\cdot\mathbf{r}\big)\times\mathbf{V}_b + \big(F\cdot\mathbf{r}\big)\times \frac{\partial \mathbf{V}_b}{\partial \mathbf{q}} \Big],\]

where \(F_i = C_{D,i}A_i\max(0,\mathbf{n}_i^\top\mathbf{V}_b)\) and \(\mathbf{r}\) stacks the lever arms \((\mathbf{r}_i-\mathbf{r}_{\mathrm{COM}})\).

Parameters:

  • sat (Satellite) – Satellite instance providing the COM.

  • x (numpy.ndarray) – Full spacecraft state containing the attitude quaternion \(\mathbf{q}\).

  • os (Orbital_State) – Provides \(\mathbf{V}_b\), density \(\rho\), and the quaternion derivative \(\partial \mathbf{V}_b / \partial \mathbf{q}\).

Returns:

Quaternion Jacobian ∂T_drag/∂q, shape (3, 4).

Return type:

numpy.ndarray

torque_qqhess(sat, x, os)[source]¶

Compute the Hessian of drag torque with respect to the attitude quaternion.

With \(\mathbf{q}\) the attitude quaternion, define \(F_i(\mathbf{q}) = C_{D,i}A_i\max(0,\mathbf{n}_i^\top\mathbf{V}_b(\mathbf{q}))\). Then

\[\frac{\partial^2 \mathbf{T}_{\mathrm{drag}}}{\partial \mathbf{q}^2} = -\tfrac{1}{2}\rho\Big[ \frac{\partial^2 (F\cdot\mathbf{r})}{\partial \mathbf{q}^2}\times\mathbf{V}_b + \frac{\partial (F\cdot\mathbf{r})}{\partial \mathbf{q}}\times \frac{\partial \mathbf{V}_b}{\partial \mathbf{q}} + \big(\cdot\big)^\top + (F\cdot\mathbf{r})\times \frac{\partial^2 \mathbf{V}_b}{\partial \mathbf{q}^2} \Big],\]

where \((\cdot)^\top\) denotes the term with the cross-product factors swapped, matching the implemented symmetric pairing.

Parameters:

  • sat (Satellite) – Satellite instance providing the COM.

  • x (numpy.ndarray) – Full spacecraft state containing the attitude quaternion \(\mathbf{q}\).

  • os (Orbital_State) – Provides \(\mathbf{V}_b\), \(\rho\), and derivatives \(\partial \mathbf{V}_b / \partial \mathbf{q}\), \(\partial^2 \mathbf{V}_b / \partial \mathbf{q}^2\).

Returns:

Quaternion Hessian tensor ∂²T_drag/∂q², shape (3, 4, 4).

Return type:

numpy.ndarray

Satellite Geometry Configuration

The GeometryConfig class defines the geometric and aerodynamic properties of the satellite’s external surfaces. This configuration is used by disturbance and actuator models such as Drag_Disturbance to compute forces and torques.

Each entry in the geometry configuration represents one surface element (e.g., a panel or face) with attributes describing its physical and aerodynamic properties.

Structure of a Geometry Entry

Each geometry element is expected to contain the following ordered parameters:

Key

Description

index

Unique integer identifier for the surface element.

area

Surface area \(A_i\) [m²].

centroid

Centroid position vector \(\mathbf{r}_i\) in body frame [m].

normal

Surface normal unit vector \(\mathbf{n}_i\) in body frame.

eta_s

Specular reflection coefficient (0–1).

eta_d

Diffuse reflection coefficient (0–1).

eta_a

Absorptivity coefficient (0–1).

CD

Drag coefficient \(C_{D,i}\) of the surface.
Parameters:

  • geometry (list[dict[str, any]]) – List of dictionaries defining geometry parameters for all satellite surfaces. Each entry must include the keys listed above.

  • geometry_faces (List[GeometryFace])

class ADCS.satellite_hardware.disturbances.Prop_Disturbance(torque_nominal, noise=None, estimate_dist=False)[source]¶

Bases: Disturbance

Propulsion Disturbance Model

This class represents residual or imperfectly modeled propulsion-induced torques acting on the spacecraft body. These torques can arise due to thrust misalignment, asymmetric propellant expulsion, or reaction forces during maneuvering.

The model assumes a constant nominal disturbance torque with optional stochastic noise.

Model Overview

The total disturbance torque is expressed as:

\[\mathbf{T}_{\mathrm{prop}} = \mathbf{T}_{0} + \mathbf{n}(t)\]

where:

  • \(\mathbf{T}_{0}\) — Nominal (constant) propulsion disturbance torque [N·m],

  • \(\mathbf{n}(t)\) — Zero-mean stochastic noise term [N·m].

This disturbance is independent of attitude or orbital parameters, and thus its attitude derivatives are zero.

Parameters:

  • torque_nominal (numpy.ndarray) – Nominal propulsion disturbance torque vector [N·m], shape (3,).

  • noise (Noise) – Noise model instance providing stochastic variations in the disturbance torque.

  • estimate_dist (bool)

class ADCS.satellite_hardware.disturbances.SRP_Disturbance(config)[source]¶

Solar Radiation Pressure (SRP) Disturbance Model

This class models the solar radiation pressure (SRP) torque acting on a satellite. The SRP torque arises from the momentum exchange between sunlight and the satellite’s external surfaces due to reflection and absorption.

The model computes the total torque by summing contributions from all illuminated surfaces defined in a GeometryConfig.

Physical Model

The solar radiation pressure force on a surface element is given by:

\[\mathbf{F}_i = -P_{\odot} A_i \max(0, \mathbf{n}_i \cdot \mathbf{s}_b) \left[ (1 - \eta_s) \mathbf{s}_b + 2 \eta_s (\mathbf{n}_i \cdot \mathbf{s}_b) \mathbf{n}_i + \tfrac{2}{3} \eta_d \mathbf{n}_i \right]\]

where:

  • \(P_{\odot} = \dfrac{S_0}{c}\) is the solar radiation pressure [N/m²],

  • \(S_0\) — Solar constant (\(1367~\mathrm{W/m^2}\)),

  • \(c\) — Speed of light in vacuum [m/s],

  • \(A_i\) — Area of the i-th surface [m²],

  • \(\mathbf{n}_i\) — Surface normal vector in body frame,

  • \(\mathbf{s}_b\) — Unit Sun direction vector in body frame,

  • \(\eta_s, \eta_d, \eta_a\) — Specular, diffuse, and absorptive coefficients.

The total torque on the spacecraft is:

\[\mathbf{T}_{\mathrm{SRP}} = \sum_i (\mathbf{r}_i - \mathbf{r}_{\mathrm{COM}}) \times \mathbf{F}_i\]

Only surfaces facing the Sun (\(\mathbf{n}_i \cdot \mathbf{s}_b > 0\)) contribute to the disturbance. If the spacecraft is in eclipse, the torque is zero.

Parameters:

Surface centroids in body coordinates [m], shape (N, 3).

Type:

numpy.ndarray

Surface normal unit vectors in body frame, shape (N, 3).

torque(sat, x, os)[source]¶

Compute the solar radiation pressure (SRP) torque on the spacecraft in the body frame.

The implemented model forms the Sun-look direction \(\mathbf{s}_b = \frac{\mathbf{S}_b - \mathbf{R}_b}{\lVert \mathbf{S}_b - \mathbf{R}_b\rVert}\) (using normalize()) and uses \(\cos\gamma_i = \mathbf{n}_i^\top \mathbf{s}_b\). With the clamped incidence \(\cos^+ \gamma_i = \max(0,\cos\gamma_i)\), the per-face scalar multipliers are

\[m_{s,i} \;=\; A_i\,(\eta_a+\eta_d)\,\cos^+\gamma_i, \qquad m_{n,i} \;=\; A_i\!\left(2\,\eta_s\,(\cos^+\gamma_i)^2 + \tfrac{2}{3}\,\eta_d\right),\]

and the SRP torque is

\[\mathbf{T}_{\mathrm{SRP}} \;=\; -\frac{S_0}{c}\; \sum_i \Big[ m_{s,i}\,(\mathbf{r}_i-\mathbf{r}_{\mathrm{COM}})\times \mathbf{s}_b \;+\; m_{n,i}\,(\mathbf{r}_i-\mathbf{r}_{\mathrm{COM}})\times \mathbf{n}_i \Big],\]

where \(S_0\) is the solar constant and \(c\) the speed of light.

Illumination is checked via is_sunlit(); if the spacecraft is not sunlit, the torque is zero.

Parameters:

  • sat (Satellite) – Satellite object providing the center-of-mass sat.COM (body frame) and geometry.

  • x (numpy.ndarray) – Full spacecraft state (contains the attitude quaternion used to form body-frame vectors).

  • os (Orbital_State) – Provides \(\mathbf{S}_b\) (Sun vector), \(\mathbf{R}_b\) (spacecraft position), and illumination status.

Returns:

SRP torque vector in the body frame [N·m], shape (3,).

Return type:

numpy.ndarray

torque_qjav(sat, x, os)[source]¶

Jacobian of the SRP torque with respect to the attitude quaternion.

Let \(\mathbf{q}\) be the attitude quaternion inside \(x\). Define \(\mathbf{s}_b(\mathbf{q}) = \frac{\mathbf{S}_b-\mathbf{R}_b}{\lVert \mathbf{S}_b-\mathbf{R}_b\rVert}\) and \(\cos\gamma_i(\mathbf{q})=\mathbf{n}_i^\top\mathbf{s}_b(\mathbf{q})\). Using the clamped incidence \(\cos^+\gamma_i=\max(0,\cos\gamma_i)\), its derivative is

\[\frac{\partial \cos^+\gamma_i}{\partial \mathbf{q}} \;=\; H\!\big(\cos\gamma_i\big)\; \mathbf{n}_i^\top\frac{\partial \mathbf{s}_b}{\partial \mathbf{q}},\]

where \(H(\cdot)\) is the Heaviside function (subgradient at zero). With

\[m_{s,i} = A_i(\eta_a+\eta_d)\,\cos^+\gamma_i, \qquad m_{n,i} = A_i\!\left(2\,\eta_s(\cos^+\gamma_i)^2 + \tfrac{2}{3}\eta_d\right),\]

the Jacobian follows from the product rule

\[\frac{\partial \mathbf{T}_{\mathrm{SRP}}}{\partial \mathbf{q}} \;=\; -\frac{S_0}{c}\sum_i \Big[ \frac{\partial m_{s,i}}{\partial \mathbf{q}}\, (\mathbf{r}_i-\mathbf{r}_{\mathrm{COM}})\times \mathbf{s}_b \;+\; m_{s,i}\,(\mathbf{r}_i-\mathbf{r}_{\mathrm{COM}})\times \frac{\partial \mathbf{s}_b}{\partial \mathbf{q}} \;+\; \frac{\partial m_{n,i}}{\partial \mathbf{q}}\, (\mathbf{r}_i-\mathbf{r}_{\mathrm{COM}})\times \mathbf{n}_i \Big],\]

with

\[\frac{\partial m_{s,i}}{\partial \mathbf{q}} = A_i(\eta_a+\eta_d)\,H(\cos\gamma_i)\, \mathbf{n}_i^\top\frac{\partial \mathbf{s}_b}{\partial \mathbf{q}}, \qquad \frac{\partial m_{n,i}}{\partial \mathbf{q}} = A_i\Big[ 4\eta_s\,\cos^+\gamma_i\,H(\cos\gamma_i)\, \mathbf{n}_i^\top\frac{\partial \mathbf{s}_b}{\partial \mathbf{q}} \Big].\]

In code, \(\frac{\partial \mathbf{s}_b}{\partial \mathbf{q}}\) is produced via normed_vec_jac() applied to \(\mathbf{S}_b-\mathbf{R}_b\).

Parameters:

  • sat (Satellite) – Satellite instance providing the COM location.

  • x (numpy.ndarray) – Full spacecraft state containing the quaternion \(\mathbf{q}\).

  • os (Orbital_State) – Provides \(\mathbf{S}_b, \mathbf{R}_b\) and their quaternion derivatives.

Returns:

Jacobian matrix ∂T_SRP/∂q, shape (3, 4).

Return type:

numpy.ndarray

torque_qqhess(sat, x, os)[source]¶

Hessian of the SRP torque with respect to the attitude quaternion.

Let \(\mathbf{q}\) be the attitude quaternion and abbreviate \(\mathbf{r}_i'=\mathbf{r}_i-\mathbf{r}_{\mathrm{COM}}\), \(\mathbf{s}_b=\mathbf{s}_b(\mathbf{q})\), \(\cos^+\gamma_i=\max(0,\mathbf{n}_i^\top\mathbf{s}_b)\). Using the Jacobian in torque_qjav() and the product rule, the second derivative is

\[\frac{\partial^2 \mathbf{T}_{\mathrm{SRP}}}{\partial \mathbf{q}^2} \;=\; -\frac{S_0}{c}\sum_i \Big[ \frac{\partial^2 m_{s,i}}{\partial \mathbf{q}^2}\, (\mathbf{r}_i'\times \mathbf{s}_b) \;+\; 2\,\frac{\partial m_{s,i}}{\partial \mathbf{q}}\times \frac{\partial (\mathbf{r}_i'\times \mathbf{s}_b)}{\partial \mathbf{q}} \;+\; m_{s,i}\,\mathbf{r}_i'\times \frac{\partial^2 \mathbf{s}_b}{\partial \mathbf{q}^2} \;+\; \frac{\partial^2 m_{n,i}}{\partial \mathbf{q}^2}\, (\mathbf{r}_i'\times \mathbf{n}_i) \Big],\]

where the terms involving \(\cos^+\gamma_i\) inherit a Heaviside factor \(H(\cos\gamma_i)\) and are undefined exactly at \(\cos\gamma_i=0\) (a measure-zero set in practice). The implementation follows this structure by building first- and second-order derivatives of the clamped incidence and of \(\mathbf{s}_b(\mathbf{q})\).

Parameters:

  • sat (Satellite) – Satellite instance providing the COM location.

  • x (numpy.ndarray) – Full spacecraft state containing the quaternion \(\mathbf{q}\).

  • os (Orbital_State) – Provides \(\mathbf{S}_b, \mathbf{R}_b\) and their first/second quaternion derivatives.

Returns:

Quaternion Hessian tensor of the SRP torque, shape (3, 4, 4).

Return type:

numpy.ndarray
