ADCS.satellite_hardware.actuators.reaction_wheel module¶

class ADCS.satellite_hardware.actuators.reaction_wheel.RW(axis, max_torque, J, h, h_max, bias=None, noise=None, h_meas_noise=None, estimate_bias=False)[source]¶

Bases: Actuator

Reaction Wheel (RW) Actuator Model

This class represents a single-axis Reaction Wheel (RW) used in satellite attitude control systems. It models how torque commands generate body torques and internal momentum changes through conservation of angular momentum.

Model Description

The reaction wheel applies a control torque to the spacecraft body by changing its spin rate. The torque applied to the spacecraft is defined as:

\[\mathbf{T}_{\mathrm{RW}} = \mathbf{a}_{\mathrm{axis}} \, u\]

where:

  • \(\mathbf{a}_{\mathrm{axis}}\) — Reaction wheel spin axis (unit vector in body frame)

  • \(u\) — Commanded motor torque input [N·m]

The change in wheel angular momentum is governed by:

\[\dot{\mathbf{h}} = -\mathbf{T}_{\mathrm{RW}}\]

ensuring angular momentum conservation between the spacecraft and the wheel.

Optional bias and noise models can be included to represent realistic actuator imperfections such as constant offsets or stochastic disturbances.

Parameters:

  • axis (numpy.ndarray) – Unit vector (3,) defining the spin axis of the reaction wheel in the spacecraft body frame.

  • max_torque (float) – Maximum torque u the motor can produce [N·m].

  • J (numpy.ndarray) – Moment of inertia of the wheel [kg·m²].

  • h (numpy.ndarray) – Current angular momentum of the wheel [N·m·s].

  • h_max (numpy.ndarray) – Maximum allowable stored momentum (saturation limit) [N·m·s].

  • bias (Bias, optional) – Bias model instance representing constant or time-varying actuator offset.

  • noise (Noise, optional) – Noise model instance representing stochastic torque fluctuations.

  • estimate_bias (bool, optional) – If True, includes actuator bias in the state estimation process.

  • h_meas_noise (Noise)

torque(u, x, os, dmode=None)[source]¶

Compute the reaction wheel body torque.

The torque generated by the wheel and applied to the spacecraft body is:

\[\mathbf{T}_{\mathrm{RW}} = \mathbf{a}_{\mathrm{axis}} (u + b) + \mathbf{n}\]

where:

  • \(u\) — Commanded motor torque [N·m]

  • \(b\) — Bias term (if bias=True)

  • \(\mathbf{n}\) — Stochastic noise (if noise=True)

  • \(\mathbf{a}_{\mathrm{axis}}\) — Wheel axis in body frame

Parameters:

  • u (float) – Commanded torque applied to the wheel motor [N·m].

  • x (numpy.ndarray) – Current spacecraft state vector.

  • os (Orbital_State) – Current orbital state, providing access to os.J2000 for bias evolution.

  • dmode (DisturbanceMode)

Returns:

Torque vector applied to the spacecraft body [N·m], shape (3,).

Return type:

numpy.ndarray

Warning

Emits a UserWarning if |u| > self.u_max.
