# Planner extra material

This directory contains Planner material that is not part of the paper-ready
datasets:

- `figures/` — generated comparison, trajectory, histogram, and multi-goal figures.
- `scripts/` — exploratory, debugging, generation, loading, and plotting scripts.
- `outputs/` — legacy `.sim` output files.
- `legacy/` — the older Planner scripts and serialized `output_data` results.
- `cache/` — Python bytecode cache files.
- `requirements-planner.txt` — the Planner virtual-environment requirements.

The paper-facing material remains under `../paper/`, with `single_goal/` and
`multi_goal/` kept separate.
