# P1.2 — One PD law across actuator complements (portability)

**Goal.** Demonstrate the framework's portability: the *same* control law
(framework LP-PD) and the *same* canonical gains, run on 3MTQ+0RW / 3MTQ+1RW /
3MTQ+3RW and on two task types, give consistent behaviour *modulo actuator
authority*. Backs Paper 1's "one law, multiple platforms" claim.

## Environment
- Python 3.12.13, NumPy 2.2.6, SciPy 1.15.3; Patricks-MacBook-Pro.local
  (Darwin 25.4.0, arm64).
- Branch `paper2-datagen`, working-tree commit `458aa70` + this task's patch
  (additive `MTQ_w_RW_LP.last_alpha` + `_paper1_sim` alpha recording),
  committed in the same changeset. SALTRO `fd7d24c`.

## Method (paper-citable)
- One controller for all cells: `MTQ_w_RW_LP`, **canonical Paper-1 PD gains
  `(kp, kd, kc) = (5e-5, 1e-3, 1e-3)`** — the same gains used by the
  controllability / allocation (FIG-ALLOC) / SAMELAW figures, confirmed by
  inspection, so P1.2 inherits a consistent testbed.
- 3 configs × 2 task types × 100 trials. **Paired** seeds (seed = run_id), so a
  given trial sees the same IC rate/attitude and the same goal across configs
  (RW momentum IC sized per config). tf = 1000 s, dt = 2 s.
- Tasks: *vector* = boresight-to-ECI pointing (`ECI_Goal`; Paper-1 satellites
  have body boresight [0,0,1], so `metrics.boresight_error_deg` is correct);
  *full* = 3-axis attitude (`Fixed_Attitude_Goal`, random target quaternion,
  error = `2 acos|<q,q_ref>|`).
- Convergence: final error < 5°. **Saturation `1 − ᾱ`**: `ᾱ` is the LP
  allocation scale (fraction of the requested torque physically achievable),
  newly exposed as `controller.last_alpha` and averaged over the run. This is
  the gain-robust *relative* metric the framing lock asks for.

## Reading guide / honest framing
- **The saturation `1 − ᾱ` is the clean portability story** and it is monotone
  in actuator authority on *both* tasks: 3+0 ≈ 0.998–0.999 (the LP is almost
  always asking for torque the hardware cannot deliver) → 3+1 ≈ 0.22 (vector) /
  0.52 (full) → 3+3 = 0.000 (never saturates). Because `1 − ᾱ` is dimensionless
  and gain-independent, it survives the LP1↔LP2 gain-difference framing lock —
  **report it, not the absolute convergence percentages alongside P2.1.**
- **Diagonal (controllability-appropriate) cells are the main result.** 3+3
  converges 100% on both tasks at 0.01° with zero saturation — full authority.
  3+1 partially succeeds (71% vector, 38% full): one wheel plus magnetic gives
  most of the boresight task and a marginal full-attitude task.
- **Off-diagonal 3MTQ+0RW / full is the negative control** and behaves exactly
  as controllability predicts: 0% converged, saturation ≈ 1.0. Magnetic-only
  actuation cannot hold a commanded 3-axis attitude. *Honest negative result,
  not a defect.*
- **3MTQ+0RW / vector reads 1%** despite being controllability-*appropriate* in
  principle (magnetic-only inertial pointing is achievable, cf. Lovera). The
  saturation metric explains the gap: at these (deliberately shared, harsh)
  gains the LP-PD requests torques the magnetorquers cannot deliver (⟂B + low
  authority), so it saturates (1 − ᾱ ≈ 1.0) and does not settle within 1000 s.
  This is precisely the "modulo actuator authority" caveat — the *law* ports
  cleanly; the *achieved* performance is bounded by hardware, and the bound is
  quantified by `1 − ᾱ`.
- **Do not parade absolute convergence vs P2.1.** Same testbed/gains as the
  controllability/allocation figures; the message is *relative* consistency
  across configs (paired Δ vs the most-capable 3+3, saturation trend), not
  headline convergence numbers.
