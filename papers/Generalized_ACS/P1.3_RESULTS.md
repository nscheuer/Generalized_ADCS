# P1.3 — Four control laws through the framework (genuine Wie cell)

**Goal.** Complete the "swap the control law" demonstration by adding a
*genuine* Wie control law (distinct from the framework LP-PD) as a fourth
cell, and run all four laws at 100 trials through one identical actuator
interface. Paper 1, Section V-B.

## Environment
- Python 3.12.13, NumPy 2.2.6, SciPy 1.15.3
- Host: Patricks-MacBook-Pro.local (Darwin 25.4.0, arm64)
- Branch `paper2-datagen`, working-tree commit `017a939` (+ this task's patch,
  committed in the same changeset). SALTRO submodule `fd7d24c`.

## What changed (premise correction)
The existing `generate_fig_tab_difflaw.py` already had a law literally named
**"Wie"**, but its implementation was `MTQ_w_RW_LP(...)` — i.e. the framework
**LP-PD** (linear quaternion PD + LP allocation). There was no genuine,
distinct Wie controller anywhere in the tree. Two corrections were made:
1. The mislabelled "Wie" cell in the single-run difflaw is renamed **LP-PD**.
2. A genuine **`MTQ_Wie`** controller was implemented: Wie's *inertia-weighted*
   eigenaxis quaternion-feedback regulator (Wie, *Space Vehicle Dynamics and
   Control*, 2nd ed.; Wie, Weiss & Arapostathis, JGCD 12(3), 1989):
   `tau_fb = -J (k_p q_e) - J (k_d w_err)` + shared gyroscopic decoupling. It
   subclasses `MTQ_w_RW_LP` and overrides only the control law, inheriting the
   identical LP allocation + torque-free desaturation (the law-agnostic
   interface claim is therefore demonstrated by construction).

**Why a full-attitude task.** The framework's attitude-error routine already
enforces the shortest-rotation convention, so on a *vector-pointing* (boresight)
task a faithful Wie PD collapses onto the LP-PD (the original author's labelling
was, in that sense, defensible). To exercise a genuinely distinct Wie law the
comparison is run on a **full 3-axis attitude goal** (`Fixed_Attitude_Goal`,
random target quaternion). On the asymmetric inertia `J = diag(0.022, 0.022,
0.004)` the inertia-weighting drives the low-inertia z-axis ~5.5x more gently
than scalar PD — the eigenaxis shaping Wie derives — so Wie and LP-PD are
numerically distinct here (verified: per-axis feedback torque differs only on
the z-axis by design).

## Methodology (paper-citable)
- Config **3MTQ+1RW**; full-attitude pointing; one fixed random target
  quaternion per trial, **paired across laws** (seed = run_id; targets from
  `default_rng(10000 + run_id)`), so all four laws see identical scenarios.
- 100 trials, tf = 1000 s, dt = 2 s. Metric: full attitude-error angle
  `2 acos(|<q(t), q_ref>|)`; convergence = final error < 5°.
- Gains: LP-PD `(kp,kd,kc) = (5e-5, 1e-3, 1e-3)` (canonical Paper-1 PD gains,
  shared with the controllability/allocation/SAMELAW figures); Wie
  `(kp,kd) = (5e-5/0.022, 1e-3/0.022)` chosen so `J*kp` matches LP-PD's kp on
  the high-inertia axes (clean attribution of the difference to inertia-
  weighting); Lovera `(1e-3, 5e-3, eps=1)`; Wisniewski `lambda_s=0.01 I,
  lambda_q=0.002 I`.

## Reading guide / honest caveats
- **Wie is genuinely distinct from LP-PD** (median 29.9° vs 39.8°; paired
  Δ −1.4° mean, i.e. comparable, neither dominates) — the framework accepts a
  second, structurally different quaternion law through the *same* interface.
  This is the intended demonstration: *the pipeline is law-agnostic*, not that
  one law wins.
- **Lovera and Wisniewski fail (0%)** on this task. This is **controllability-
  appropriate, not a defect**: both are magnetic-only laws designed for
  *inertial vector pointing*, not full 3-axis attitude regulation. Run
  off-design on a full-attitude goal with a single reaction wheel, they cannot
  hold all three axes. Their on-design (vector-pointing) comparison is the
  single-run `FIG-DIFFLAW` (now correctly labelled LP-PD/Lovera/Wisniewski).
- **Absolute convergence is modest even for LP-PD/Wie (35–40%)**: full-attitude
  regulation on 3MTQ+1RW is controllability-limited (3 MTQ give instantaneous
  rank-2 torque ⟂ B; one RW adds a single axis; full 3-axis authority accrues
  only slowly over the orbit). Report relative/paired metrics, not absolutes —
  consistent with the LP1↔LP2 framing lock. The diagonal story is "framework
  PD-family laws partially succeed; off-design magnetic laws do not."
