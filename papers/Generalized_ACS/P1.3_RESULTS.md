# P1.3 — Four control laws through the framework (genuine Wie cell)

**Goal.** Complete the "swap the control law" demonstration: four control laws
routed through *one* framework actuator interface (LP allocation + torque-free
desaturation, MTQ+RW), on 3MTQ+1RW, 100-trial paired MC. Paper 1, Section V-B.

## Environment
- Python 3.12.13, NumPy 2.2.6, SciPy 1.15.3; Patricks-MacBook-Pro.local
  (Darwin 25.4.0, arm64). Branch `paper2-datagen`, this changeset. SALTRO `fd7d24c`.

## What changed (v2 — RW-enabled, two tasks)
1. **Genuine `MTQ_Wie`** added: Wie's *inertia-weighted* eigenaxis quaternion-
   feedback regulator `tau = -J(kp q_e + kd w_err)` + shared gyroscopic
   decoupling (Wie, *Space Vehicle Dynamics and Control*, 2nd ed.). On the
   asymmetric inertia `J = diag(0.0314, 0.0341, 0.0100)` it drives the low-
   inertia axis more gently than scalar PD — genuinely distinct from LP-PD.
2. The mislabelled "Wie" in the single-run `FIG-DIFFLAW` is renamed **LP-PD**.
3. **All four laws are now framework-allocated (MTQ+RW).** The published Lovera
   and Wisniewski laws are *magnetic-only* — they command magnetorquers and
   never actuate the reaction wheel (`u_out[rw]=0`). That made the earlier
   full-attitude run read 0% for them — not a fair test. Their *control laws*
   are kept but routed through the LP allocation (`MTQ_Lovera_LP`,
   `MTQ_Wisniewski_LP`), so the wheel is used and all four share one allocation
   interface — the apples-to-apples comparison.
4. Run on **both** task types and a **longer horizon (tf = 2000 s)** so the
   (slow) magnetic-law convergence has time to complete.

## Methodology (paper-citable)
- Config 3MTQ+1RW. 100 trials, paired seeds (seed=run_id), tf=2000 s, dt=2 s.
- Tasks: **vector** (`ECI_Goal`, boresight error, Paper-1 sat boresight
  [0,0,1]) and **full** (`Fixed_Attitude_Goal`, random target quaternion,
  error `2 acos|<q,q_ref>|`). Convergence = final error < 5°.
- Gains: LP-PD `(5e-5, 1e-3, 1e-3)`; Wie `(5e-5/0.022, 1e-3/0.022)`; Lovera
  `(kp,kd,eps)=(1e-3, 5e-3, 1)`; Wisniewski `Λ_s=0.01 I, Λ_q=0.002 I`; all with
  the framework LP allocation `c_gain=1e-3`.

## Reading guide / honest framing
- **The framework hosts all four control laws through one interface** — the
  headline. On the **vector** (on-design) task the four are *comparable*
  (53–70% convergence, medians 0.06–3.5°): the magnetic-only literature laws
  (Lovera, Wisniewski), once routed through the LP allocation so they use the
  reaction wheel, match LP-PD. That is the "pipeline accepts any law cleanly"
  claim, demonstrated apples-to-apples.
- **Wie is genuinely distinct from LP-PD** (full task: median 17.9° vs 14.5°,
  paired Δ −1.7°; comparable, neither dominates) — a second, structurally
  different quaternion law through the same interface.
- **Full 3-axis attitude is harder for all** (47% down to 22%): 3MTQ+1RW gives
  full authority only over time (3 MTQ instantaneously rank-2 ⟂ B; one wheel
  adds one axis). LP-PD/Wie lead; the magnetic laws trail but **now converge**
  (22–37%, vs 0% when the RW was idle) — your hypothesis (RW + longer horizon)
  confirmed.
- **What the reaction wheel buys (RW-idle rows).** The *published* magnetic-only
  Lovera/Wisniewski (reaction wheel commanded to zero) converge **0%** on full
  attitude (mean ~111–113°, essentially tumbling) — exactly as controllability
  predicts: 3 magnetorquers alone cannot hold an arbitrary 3-axis attitude. The
  *same* control laws, routed through the framework so they also command the one
  reaction wheel, jump to **22% / 37%**. So the framework contribution is sharply
  quantified here: the third-axis authority that turns "0%, tumbling" into a
  converging law comes entirely from the allocation using the wheel, not from the
  control law. (Dashed traces on the full panel.)
- **Allocation caveat (per Patrick's note).** All four use the LP "max torque in
  the requested direction" + torque-free desaturation. With a single RW the LP
  direction-maximiser exploits the wheel only modestly; the alternative
  "recreate the torque via the nominal actuation map then allocate"
  (`Controller.build_torque_to_u_matrix_pinv`) would lean on the wheel harder
  and is the natural next lever if fuller RW usage is wanted.
- The plain magnetic-only `MTQ_Lovera`/`MTQ_Wisniewski` (RW idle) remain
  available; the single-run vector `FIG-DIFFLAW` documents their published form.
