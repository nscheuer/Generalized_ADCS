ADCS.orbits.orbital_state module¶

class ADCS.orbits.orbital_state.Orbital_State(ephem, J2000, R, V, S=None, B=None, rho=None, density_model=None, fast=False)[source]¶

Bases: object

Represents the complete orbital state of a spacecraft in the Earth-centered inertial (ECI) frame, including position, velocity, environmental vectors, and derived coordinate transformations.

This class provides methods for orbit propagation, Jacobian computation, and coordinate transformations between ECI, ECEF, ENU, and geocentric frames. It also integrates environmental modeling such as atmospheric density, magnetic field, and solar vector direction.

Notes

  • Time conversions use the Skyfield timescale interface (\(t_{TAI}\), \(t_{UTC}\)).

  • Magnetic field computations use the IGRF model via ppigrf.

  • The class supports both Euler and RK4 propagation of orbital state vectors:

\[\frac{d\mathbf{r}}{dt} = \mathbf{v}, \quad \frac{d\mathbf{v}}{dt} = -\frac{\mu_E \mathbf{r}}{r^3} + \mathbf{a}_{J2}\]

where \(\mu_E\) is Earth’s gravitational constant and \(\mathbf{a}_{J2}\) is the optional J₂ perturbation acceleration term.

average(orbital_state_2, ratio=0.5, fast=False)[source]¶

Compute the weighted average between this orbital state and another Orbital_State instance.

Parameters:

  • orbital_state_2 (Orbital_State) – Second orbital state to interpolate toward.

  • ratio (float, optional) – Interpolation factor between 0 and 1. - 0 → returns this state - 1 → returns orbital_state_2 - 0.5 → midpoint (default)

  • fast (bool)

Returns:

New Orbital_State object representing the interpolated state.

Return type:

Orbital_State

Notes

The averaging is performed linearly on each vector quantity:

\[\begin{split}\mathbf{R}_{avg} &= (1 - \alpha)\mathbf{R}_1 + \alpha\mathbf{R}_2 \\ \mathbf{V}_{avg} &= (1 - \alpha)\mathbf{V}_1 + \alpha\mathbf{V}_2 \\ \mathbf{S}_{avg} &= (1 - \alpha)\mathbf{S}_1 + \alpha\mathbf{S}_2 \\ \mathbf{B}_{avg} &= (1 - \alpha)\mathbf{B}_1 + \alpha\mathbf{B}_2 \\ \rho_{avg} &= (1 - \alpha)\rho_1 + \alpha\rho_2\end{split}\]

where \(\alpha\) is the weighting ratio. Atmospheric models are preserved from the current object, but a warning is issued if their altitude–density grids do not match.

orbit_dynamics(J2_perturbation_on=True)[source]¶

Compute the orbital dynamics (two-body or J2-perturbed).

Parameters:

J2_perturbation_on (bool, optional) – If True, includes the Earth’s oblateness correction (J₂ term).

Returns:

  • r_dot (ndarray, shape (3,)) – Time derivative of position vector \(\dot{\mathbf{r}}\) in ECI frame.

  • v_dot (ndarray, shape (3,)) – Time derivative of velocity vector \(\dot{\mathbf{v}}\) in ECI frame (acceleration).

Return type:

ndarray

Notes

The central gravitational acceleration is:

\[\dot{\mathbf{v}} = -\frac{\mu_E \mathbf{r}}{\|\mathbf{r}\|^3}\]

and the optional J₂ perturbation term is:

\[\begin{split}\mathbf{a}_{J2} = \frac{3}{2} J_2 \frac{\mu_E R_E^2}{r^5} \begin{bmatrix} x \left(5 \frac{z^2}{r^2} - 1\right) \\ y \left(5 \frac{z^2}{r^2} - 1\right) \\ z \left(5 \frac{z^2}{r^2} - 3\right) \end{bmatrix}\end{split}\]
orbit_dynamics_jacobians(J2_perturbation_on=True)[source]¶

Compute the Jacobian matrices of the orbital dynamics equations.

Parameters:

J2_perturbation_on (bool, optional) – Enables J₂ perturbation effects in the Jacobian.

Returns:

  • drd_dr (ndarray, shape (3,3)) – Partial derivative \(\frac{\partial \dot{\mathbf{r}}}{\partial \mathbf{r}}\).

  • drd_dv (ndarray, shape (3,3)) – Partial derivative \(\frac{\partial \dot{\mathbf{r}}}{\partial \mathbf{v}}\).

  • dvd_dr (ndarray, shape (3,3)) – Partial derivative \(\frac{\partial \dot{\mathbf{v}}}{\partial \mathbf{r}}\).

  • dvd_dv (ndarray, shape (3,3)) – Partial derivative \(\frac{\partial \dot{\mathbf{v}}}{\partial \mathbf{v}}\).

Return type:

ndarray

Notes

For the two-body problem:

\[\frac{\partial \dot{\mathbf{v}}}{\partial \mathbf{r}} = -\frac{\mu_E}{r^3} \left[ I - 3 \frac{\mathbf{r}\mathbf{r}^T}{r^2} \right]\]

When J₂ is included, additional perturbation derivatives are added according to the Earth’s gravitational potential expansion.

propagate_jacobians(dt, J2_perturbation_on=True)[source]¶

Propagate the state-transition Jacobians using Euler integration.

Parameters:

  • dt (float) – Time step [s].

  • J2_perturbation_on (bool, optional) – If True, include J₂ effects.

Returns:

  • dr1__dr0 (ndarray, shape (3,3)) – ∂r₁/∂r₀.

  • dr1__dv0 (ndarray, shape (3,3)) – ∂r₁/∂v₀.

  • dv1__dr0 (ndarray, shape (3,3)) – ∂v₁/∂r₀.

  • dv1__dv0 (ndarray, shape (3,3)) – ∂v₁/∂v₀.

Return type:

ndarray

Notes

Linearized update:

\[\begin{split}\frac{d}{dt} \begin{bmatrix} \mathbf{r} \\ \mathbf{v} \end{bmatrix} = \begin{bmatrix} 0 & I \\ A & 0 \end{bmatrix} \begin{bmatrix} \mathbf{r} \\ \mathbf{v} \end{bmatrix}\end{split}\]

Propagate the orbital state forward in time using first-order integration.

Parameters:

  • dt (float) – Time step [s].

  • J2_perturbation_on (bool, optional) – If True, include J₂ perturbation effects.

  • fast (bool)

Returns:

New orbital state at \(t + \Delta t\).

Return type:

Orbital_State

Notes

This uses a simple Euler integration step:

\[\begin{split}\mathbf{r}_{k+1} = \mathbf{r}_k + \dot{\mathbf{r}}_k \Delta t \\ \mathbf{v}_{k+1} = \mathbf{v}_k + \dot{\mathbf{v}}_k \Delta t\end{split}\]
propagate_orbit_rk4(dt, J2_perturbation_on=True, fast=True)[source]¶

Propagate the orbit using 4th-order Runge–Kutta (RK4) integration.

Parameters:

  • dt (float) – Time step [s].

  • J2_perturbation_on (bool, optional) – If True, include J₂ perturbation effects.

  • fast (bool)

Returns:

Updated orbital state after RK4 integration.

Return type:

Orbital_State

Notes

Runge–Kutta integration steps:

\[\begin{split}k_1 = f(t, y) \\ k_2 = f(t + \tfrac{1}{2}\Delta t, y + \tfrac{1}{2}k_1 \Delta t) \\ k_3 = f(t + \tfrac{1}{2}\Delta t, y + \tfrac{1}{2}k_2 \Delta t) \\ k_4 = f(t + \Delta t, y + k_3 \Delta t) \\ y_{k+1} = y_k + \frac{\Delta t}{6} (k_1 + 2k_2 + 2k_3 + k_4)\end{split}\]
