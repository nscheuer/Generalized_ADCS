ADCS.satellite_hardware.actuators.actuator module¶

class ADCS.satellite_hardware.actuators.actuator.Actuator(axis, u_max, bias=None, noise=None, estimate_bias=False)[source]¶

Bases: object

Abstract actuator base class.

State & notation

  • Body torque: \(\boldsymbol{\tau}\in\mathbb{R}^3\).

  • Command (input): \(u\in\mathbb{R}\) with \(|u|\le u_\max\).

  • Body axis: \(\mathbf{a}=\mathrm{normalize}(\texttt{axis})\in\mathbb{S}^2\).

  • Base state: \(\mathbf{x}=[\,\boldsymbol{\omega}^\top,\ \mathbf{q}^\top\,]^\top\in\mathbb{R}^7\), where \(\boldsymbol{\omega}\in\mathbb{R}^3\) and quaternion \(\mathbf{q}\in\mathbb{R}^4\).

  • Bias state and momentum-storage state are not modeled here (zero-size shapes).

Subclasses should override the torque and derivative methods. The base implementation returns zeros with the documented shapes.
