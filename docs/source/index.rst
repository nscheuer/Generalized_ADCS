GenADCS 0.3.0
=============

GenADCS provides spacecraft attitude dynamics, environment, hardware, and
propagation components with Python, C++, and Rust backends.

The 0.3.0 release begins the GenADCS package. Documentation for earlier ADCS
releases remains available through the version selector.
