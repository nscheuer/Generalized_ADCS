Welcome to Generalized ADCS!
============================

We are happy to have you here!

Generalized ADCS (GenADCS) is a Python framework for modeling, simulating,
and analyzing spacecraft attitude determination and control systems.

Use these tutorials to learn how to build spacecraft models, configure
actuators and sensors, simulate orbital attitude dynamics, and evaluate
control and estimation methods. 

We hope you were able to install Generalized ADCS, if not, have a look at :doc:`installation guide <../installation/index>`.
You can also explore the :doc:`API reference <../ADCS>` and
:doc:`release notes <../release_notes/index>`.
